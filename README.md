# Robo Extrator - Pasta Unificada

Esta pasta contém tanto o **código-fonte** quanto o **executável** do Robô Extrator.

## Estrutura

```
Robo_Extrator/
│
├── scripts/
│   └── robo_extrator_final.py   ← Código-fonte (edite aqui)
│
├── dist/
│   └── Robo_Extrator/
│       └── Robo_Extrator.exe    ← Programa pronto para rodar
│
└── RECOMPILAR.bat               ← Clique aqui para recompilar após editar
```

## Como usar

1. **Rodar o programa:** Abra `dist\Robo_Extrator\Robo_Extrator.exe`
2. **Editar o código:** Abra e altere `scripts\robo_extrator_final.py`
3. **Compilar nova versão:** Dê dois cliques em `RECOMPILAR.bat` e aguarde

O `RECOMPILAR.bat` exige que Python e PyInstaller estejam instalados nesta máquina.
